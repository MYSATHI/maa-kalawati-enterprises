Deployment & WhatsApp Setup

  1. Set a strong SESSION_SECRET and owner credentials in the server's .env file.
  2. Use HTTPS and a persistent production session store before public launch.
  3. Set up a Meta Business app, WhatsApp Business phone number and Cloud API token.
  4. Configure webhook URL https://YOUR-DOMAIN/webhooks/whatsapp and the same verify token from .env.
  5. Collect and record customer opt-in before sending promotional WhatsApp messages.

API secrets stay on the server. Never paste a Meta token into this page or public JavaScript.
