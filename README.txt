# Maa Kalawati Enterprises — Website Preview

## Open in Chrome
1. Extract the ZIP file.
2. Open `index.html` in Google Chrome.
3. Keep the `videos` and `images` folders and `images_store_reference.jpg` beside `index.html`.
4. The store video is configured to autoplay muted and loop. Browser power-saving settings may block autoplay; visitors can press Play.

Before public launch, connect a backend, database, server-side authentication, secure media storage, HTTPS, and real form handling.
